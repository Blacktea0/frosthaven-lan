## 更新内容

- 修复局域网联机中其他玩家的 Steam 头像不显示的问题。ENet 连接现在明确协商两个通道，使游戏原有的头像分片消息能够通过独立头像通道传输。
- 改进启动失败诊断：补充 Windows API 名称、目标进程及模块枚举上下文，保留完整原始错误、内层原因、OS 错误码和内存诊断历史；不生成运行时日志文件。
- 启动初期遇到模块枚举错误 24 或 299 时，在现有启动超时内重试，避免因暂态模块加载状态立即失败。
- 增加头像通道补丁与恢复的托管回归测试，并同步更新中英文使用说明。

验证：已在同一电脑、同一 Steam 账号的两个真实游戏实例间完成修复前后对照。修复后，房主的玩家列表、角色分配弹窗及远端角色上方均显示真实 Steam 头像；客户端成功进入场景并收到角色分配。尚未覆盖跨电脑、不同账号、三人转发和重连场景。头像仍需由各玩家本机 Steam 成功获取。

本次多实例验证使用临时测试启动器。正式发行版仍要求先关闭已有游戏，再由工具启动；不提供 PID 选择或向已有实例注入的命令。

## Changes

- Fixed missing remote Steam avatars in LAN sessions. ENet connections now explicitly negotiate two channels so the game's existing avatar fragments can use their dedicated channel.
- Improved startup diagnostics with Windows API, target-process and module-enumeration context while preserving raw errors, causes, OS codes and the in-memory diagnostic history. No runtime log files are created.
- Retry early module-enumeration errors 24 and 299 within the existing startup timeout instead of failing immediately on transient module initialization.
- Added managed regression tests for the avatar-channel patch and restore behavior, and updated both language versions of the README.

Validation: compared the original and fixed behavior using two actual game instances on one computer with the same Steam account. The host's player list, assignment popup and remote-controlled character now display the Steam avatar; the client loaded the scene and received its character assignment. Cross-computer play, different accounts, three-player forwarding and reconnection have not been tested. Each player's local Steam client must still retrieve their avatar successfully.

Multiple instances were enabled only in a temporary test launcher. The production release still requires existing game instances to be closed before the tool launches the game; it exposes no PID selection or direct-injection command.

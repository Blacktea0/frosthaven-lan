## Changes

- Added LAN multiplayer compatibility with Frosthaven Retail 1.0.34574 on Steam (build `26755354`).
- Updated the in-game multiplayer prompts. The host menu hides the invite code and copy button, and the session-start notification asks the host to share their LAN IP address with friends.

## Testing and limitations

Automated build, packaging, and regression checks passed. Earlier manual testing with two game instances on one computer and one Steam account confirmed hosting and joining. The first attempt disconnected during the campaign opening. Both instances reached the first combat round after retrying from a save. Cross-computer play and longer sessions still need testing.

## 更新内容

- 适配 Steam 版霜港迷城 Retail 1.0.34574（构建号 `26755354`）的局域网联机。
- 更新游戏内联机提示。房主界面隐藏邀请码和复制按钮，开房通知会提示房主将局域网 IP 地址发给好友。

## 测试情况与使用限制

自动构建、打包和回归检查均已通过。此前在同一台电脑上使用同一个 Steam 账号进行双实例实测，验证了开房和加入，读取存档重试后双方进入了第一回合。首次测试在战役开场时断线。跨电脑联机和长时间游玩仍待验证。

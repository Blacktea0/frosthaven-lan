## 更新内容

- 普通权限模式直接启动游戏前，检查当前 Windows 用户的 Steam 活动进程和登录用户记录；要求进程 PID 与正在运行的 steam.exe 匹配，并且 ActiveUser 非零，避免 Steam 已退出或未登录时仍启动游戏并等待网络初始化超时。
- 无法确认登录时停止启动游戏，提供中英文提示：先打开 Steam 完成登录再重试，或以管理员模式通过 Steam 启动。注册表读取失败时保留原始 Windows 错误及诊断历史，仍等待 Enter 关闭，不生成运行时日志。
- 管理员模式继续通过 Steam 协议启动，不增加此登录前置检查。双语 README 已同步说明检查范围。

验证：使用本地 Windows x64 MSVC 工具链通过格式检查、工作区 Rust 测试、托管回归测试、完整五文件运行包构建与 ZIP 校验，以及启动失败诊断和 Enter 关闭测试。新增回归测试覆盖活动会话、Steam 已退出、PID 不匹配、用户未登录及无效 PID。

限制：本次没有启动或注入真实游戏，没有新增真实联机验证。本地活动会话检查不是 Steam 在线服务探测，不能保证登录后的网络连接或头像请求成功，也不能防止检查通过后 Steam 退出。

## Changes

- Before standard mode starts the game EXE directly, check the current Windows user's Steam active-process and login records. Require a matching live steam.exe PID and a nonzero ActiveUser to avoid starting the game with Steam closed or signed out and then waiting for network initialization to time out.
- If login cannot be confirmed, stop before starting the game and display Chinese or English guidance to sign in to Steam and retry, or use administrator mode to launch through Steam. Registry read failures retain original Windows errors and diagnostic history; failures still wait for Enter and create no runtime logs.
- Administrator mode continues to launch through the Steam protocol without this login precondition. Both READMEs document the scope of the check.

Validation: the local Windows x64 MSVC toolchain passed formatting, workspace Rust tests, managed regression tests, complete five-file runtime packaging and ZIP verification, and failure-diagnostic/Enter-to-close tests. New regression coverage includes an active session, a closed client, a mismatched PID, a signed-out user and an invalid PID.

Limitations: no actual game was started or injected for this change, and no additional multiplayer scenarios were tested. The local active-session check does not probe Steam's online services, guarantee connectivity or avatar retrieval after login, or prevent Steam from exiting after the check.

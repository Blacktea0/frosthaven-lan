## 更新内容

- 提高 LAN 玩家 Steam 头像清晰度：直接读取 Steam 头像 CPU 端的原始 RGBA 像素，保留实际源尺寸，替代原游戏固定 128×128 的 GPU 缩放路径，避免将采样损失固化进网络图片。
- 网络头像副本禁用 mipmap，并忽略纹理 mip 限制；不修改游戏全局画质或 Steam 原头像缓存，沿用现有头像分片与图片重建协议。
- `command status` 增加各玩家头像宽高、mipmap 状态、PNG 大小及 SHA256，便于检查发送和接收结果是否一致。诊断只经现有内存通信输出，不生成运行时日志文件。
- 增加原始 RGBA 像素保真、源尺寸保留、资源所有权、GPU 路径替换和恢复行为的托管回归测试。
- 将提交规范和发布流程集中到 `AGENTS.md`，从双语 README 移除提交规范。发布工作流现在要求提供对应版本的具体变更说明，防止发布只有通用安装说明的版本。

实测：使用同一电脑、同一 Steam 账号的两个真实游戏实例完成 LAN 连接。双方本机与远端头像均为 184×184、无 mipmap，重新编码 PNG 均为 87,202 字节，四份图片 SHA256 一致；房主玩家列表、角色分配弹窗及远端角色上方头像清晰显示。184×184 是本次 Steam 源图尺寸，不是固定分辨率或人工放大结果。尚未覆盖跨电脑、不同账号、三人转发和重连。无法从低清 Steam 源图恢复原本不存在的细节，也未确定此前用户截图中模糊的唯一原因。

正式启动器仍要求关闭已有游戏再由工具启动；双实例测试仅使用临时测试启动器。没有新增 PID 选择或向已有游戏实例注入的命令。

## Changes

- Improved remote Steam avatar clarity in LAN sessions by copying the original CPU-side RGBA pixels at their actual source dimensions, replacing the game's fixed 128×128 GPU resize and avoiding baked-in sampling loss.
- Disabled mipmaps and mip limits on the network avatar copy without changing global graphics quality or the cached Steam source. The existing image-fragment protocol and reconstruction remain in use.
- Extended `command status` with per-player avatar dimensions, mipmap state, PNG size and SHA256 to check synchronization. Diagnostics use existing memory IPC and create no runtime log files.
- Added managed regression tests for pixel fidelity, source dimensions, resource ownership, GPU conversion replacement and restore behavior.
- Centralized commit conventions and the release procedure in `AGENTS.md` and removed commit conventions from both READMEs. Releases now require version-specific change notes in addition to generic installation guidance.

Validation: two actual game instances on one computer with the same Steam account connected over LAN. All local and remote avatar copies were 184×184 with no mipmaps; their re-encoded PNGs were 87,202 bytes with identical SHA256 values across both processes. The host's player list, assignment popup and remote-controlled character displayed clear avatars. The observed 184×184 dimensions came from the Steam source, not a fixed size or artificial enlargement. Cross-computer play, different accounts, three-player forwarding and reconnection remain untested. The patch cannot recover detail absent from a low-resolution Steam source, and the precise cause of the earlier user screenshot's blur was not uniquely established.

The production launcher still requires existing games to be closed before it starts the game; only the temporary test launcher allowed two instances. No PID-selection or direct-injection command was added.

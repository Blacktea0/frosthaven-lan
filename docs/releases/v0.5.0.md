## Changes

- Improved compatibility with game updates. Some updates can now continue working without a new tool release. If the installed game is incompatible, the tool stops rather than enabling LAN mode.
- Fixed a startup timing issue that could crash the game while enabling LAN mode. This fix has passed limited local testing; other startup failures may still occur.
- Improved startup reliability by retrying temporary failures when reading game information for up to ten seconds.
- Included English and Simplified Chinese instructions in the download.

## Testing and limitations

- Automated checks passed. Local testing with two game instances on one computer and one Steam account confirmed hosting, joining, character selection, battle-goal selection, readiness, battlefield loading, first-round card and initiative synchronization, avatar display, and disconnect notifications.
- Testing has not yet covered different computers or accounts, firewall/router configurations, mixed game versions, a complete combat round, long sessions, repeated cold starts, or the Steam overlay in administrator mode.
- Steam sign-in is still required; fully offline startup is unsupported. Compatibility with future game updates is not guaranteed.
- Close any running game before opening the launcher. The released tool does not provide a dual-instance mode.

## 更新内容

- **改善游戏更新后的兼容性**：部分游戏更新后，无需等待工具更新也能继续使用。遇到不兼容的游戏版本时，工具会停止启用 LAN 模式。
- **修复一种启动崩溃问题**：修复了启用 LAN 模式时可能导致游戏崩溃的启动时序问题。已通过有限次数的本机测试，但仍可能存在其他启动故障。
- **减少临时启动失败**：读取游戏信息遇到临时错误时，会自动重试，最长等待十秒。
- **提供双语使用说明**：下载包中包含英文和简体中文说明。

## 测试情况与使用限制

- 自动检查已通过。在同一台电脑、同一 Steam 账号下使用两个游戏实例，已验证开房、加入、角色选择、战斗目标选择、准备、战场载入、第一回合选牌与先攻同步、头像显示及断线提示。
- 尚未验证跨电脑或不同账号联机、防火墙及路由器配置、不同游戏版本混用、完整战斗回合、长时间游玩、反复启动，以及管理员模式下的 Steam 叠加界面。
- 仍需登录 Steam，不支持完全离线启动；无法保证兼容未来所有游戏更新。
- 请先关闭已运行的游戏，再打开启动器。正式工具不提供游戏双开功能。
